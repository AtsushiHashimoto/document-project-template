## スキル一覧

**接頭辞 `doc-` は文書作成レイヤのスキルを表す。**
Issue・コミット・レビューの機構は research-project-template のスキルを使う。

### 準備（最初に一度）

| スキル | 用途 |
|-------|------|
| `/doc-init` | 形式制約と評価基準を一次資料から採取し `.doc/` に固定する。**一文字も書く前に実行** |

### 手順1・2: 制約の確認

| スキル | 用途 |
|-------|------|
| `/doc-constraints` | 形式制約の確認・再採取。様式・記入要領から原文を引く |
| `/doc-criteria` | 評価基準の確認・再採取。評定要素を一行ずつ表に落とす |
| `/doc-coverage` | 評定要素 → 記述箇所の対応表を作り、欠落を列挙する |

### 手順3: 直列化

| スキル | 階層 | 用途 |
|-------|------|------|
| `/doc-graph` | マクロ | 文書全体の概念依存グラフ。段落レベルの順序を決める |
| `/doc-paragraph` | ミクロ | 対象を絞った段落の中を文レベルで直列化。**書く直前に毎回** |

### 提出前

| スキル | 用途 |
|-------|------|
| `/doc-review` | 1・2・3 の全点検を通しで実行する |

### 実行順序

```
/doc-init  →  /doc-graph  →  ( /doc-paragraph → 執筆 ) × 段落数  →  /doc-coverage  →  /doc-review
                   ↑                                                      │
                   └──────── 骨格が変わる指摘が出たら戻る ────────────────┘
```
