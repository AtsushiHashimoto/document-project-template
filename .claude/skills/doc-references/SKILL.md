# Doc References — 権威ある二次資料による補強

一次資料（様式・審査基準）は**何が評価されるか**を定めるが、
**どう書けば評価されるか**は書いていない。そこを埋めるのが権威ある二次資料である。

## ★ 一次資料と混ぜない

| | 一次資料 | 二次資料 |
|---|---|---|
| 置き場所 | `worksheet/constraints.md` `worksheet/criteria.md` `worksheet/sources/` | `docs/references/` |
| 位置づけ | **制約そのもの。拘束力がある** | **解釈と作法。拘束力はない** |
| 衝突したとき | 常に勝つ | 常に負ける |
| 記録すべきこと | 原文引用、採取元、採取日 | 出典、閲覧日、**どの評定要素の補強か** |

二次資料の記述を `worksheet/criteria.md` に書き込んではいけない。
評定要素の一覧が「誰かの解釈」で汚染されると、次の版で何が変わったか分からなくなる。

## 何が「権威ある」二次資料か

| 該当する | 該当しない |
|---|---|
| 分野で定評のある指南サイト・書籍 | 個人ブログの体験談1件 |
| 学会・出版社が出す執筆ガイド、査読者向け解説 | SNSの断片的な助言 |
| 採択された文書の実例集 | 出典不明のテンプレート |
| 制度運営側の解説記事・FAQ | 生成AIの出力そのもの |
| 所属機関のURA・研究支援部門の資料 | 年度が古く更新されていない資料 |

判断がつかない場合は**ユーザーに確認する**。権威の判定は分野依存であり、
外部から一意に決められない。

## Step 1: 資料を読む

URL が与えられたらページ構成を把握し、**評価軸に関係する項目から**読む。
サイト全体を読み込もうとしない。目的は補強であって網羅ではない。

会員限定・有料の部分は読めない。**読めなかった範囲を明記する。**
読めた範囲だけで「この資料は網羅した」と書くと、後で誤った安心の根拠になる。

## Step 2: 評定要素に紐づけて抽出する

抽出は**評定要素ごと**に行う。資料の章立てではなく、`worksheet/criteria.md` の
評定要素を軸に並べ替える。紐づかない記述は落としてよい。

各項目について次を拾う。

- **推奨される構成**（順序が指定されているならそのまま）
- **NG例**。これが最も価値が高い。評価者が減点する具体的な形が分かる
- **書きすぎ・書かなすぎの目安**

## Step 3: 書き出し

`docs/references/<資料名>.md` に保存する。冒頭に必ず記録する。

```markdown
出典: <URL>
閲覧日: <YYYY-MM-DD>
読めた範囲: <公開ページのみ／会員限定は未読 等>
補強する評定要素: <criteria.md の要素ID>
```

末尾に **「本申請への適用メモ」** を置き、いま書いている文書の現状と突き合わせて
「満たしている／要追加」を具体的に書く。ここが無いと、ただの読書メモになる。

`docs/references/README.md` に索引を追記する。

## Step 4: criteria への反映

`worksheet/criteria.md` 本体は書き換えない。代わりに末尾の
**「補強資料へのポインタ」** セクションに、評定要素IDと参照先ファイルの対応を追記する。

二次資料から新たに判明した**欠落**（例: 独立評価項目に対応する記述が無い）は、
`worksheet/graph.md` の欠落一覧に追加する。これは一次資料由来の欠落と同じ扱いでよい。

## Step 5: ユーザーに追加を促す

読み終えたら、次を確認する。

- 同種の資料で他に参照すべきものはあるか
- 所属機関のURA・研究支援部門が出している資料はあるか
- 過去の採択例・不採択例で参照できるものはあるか

**ユーザーしか知らない資料が必ずある。** 聞かずに「一次資料で足りる」と判断しない。
